使用帮助

文档始终在本地打开和保存；以下操作在 Windows 版和支持键盘的设备上均可使用。

文件

新建
Ctrl + N
打开
Ctrl + O
保存
Ctrl + S
另存为
Ctrl + Shift + S
导出图片
工具栏“图片”

Windows 版可将 .md、.markdown、.mdown、.mkd 或 .txt 直接拖到窗口打开。

“图片”会先打开确认和进度弹窗。单张最长约两张竖版 A4；长文按阅读排版分块生成， 一页保存 PNG，多页打包 ZIP。生成期间可取消，网络图片失败时保留明显占位。

视图

所见即所得
Ctrl + 1
源码
Ctrl + 2
阅读
Ctrl + 3
跳转到行
Ctrl + G

三个模式中打开查找和替换都会保持当前界面；阅读模式也允许替换，内容会即时刷新。

普通文档从所见即所得或阅读视图跳转到行时，会切换到源码视图以精确定位。

查找和替换

打开面板
Ctrl + F
下一个
Enter
上一个
Shift + Enter
关闭
Esc

查找和替换均支持 \n（换行）、\r（回车）、 \t（制表符）和 \\（反斜杠）。

合并空行：查找 \n\n，替换为 \n。

保存与安全

  • 程序不会自动保存，标题栏的 * 表示有未保存更改。
  • 仅打开有效的 UTF-8 文本（可带 UTF-8 BOM）；其他编码会被拒绝，防止乱码覆盖原文件。
  • 保存采用安全替换流程，并尽量保留 BOM 和原文档的换行风格。
  • 重要文件仍建议另行备份。
PNG 图片

导出图片

导出将在确认后开始。内容较多时会自动生成多张 PNG，并打包为 ZIP。

每张图片最长约为两张竖版 A4；开始后可以随时取消。
