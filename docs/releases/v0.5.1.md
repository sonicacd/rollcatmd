# 滚猫md v0.5.1

v0.5.1 为 Windows 便携版增加“打开方式”注册和 `.md` 默认应用设置入口，并加入启动帮助及“不再展示”偏好。本次仅发布 Windows EXE，Android 继续使用 v0.5.0 APK。

## Windows 用法

先将 `rollcat-md.exe` 放到长期使用的位置，启动后打开“更多”菜单：

1. **添加到右键打开方式**：将当前运行的 EXE 注册到当前用户的打开候选中，支持 `.md`、`.markdown`、`.mdown`、`.mkd`、`.txt` 和 `.textpack`。无需管理员权限，现有默认应用保留。之后可在文件的“打开方式”中选择“滚猫md”。
2. **设为默认 .md 程序**：完成同样的注册后打开 Windows“默认应用”设置。找到 `.md`，选择“滚猫md”，并在系统设置中确认。打开设置页之后，程序提示用户继续完成选择。

支持应用专页的 Windows 11 可直接进入滚猫md的默认应用页面；较旧系统显示默认应用总页，可搜索 `.md`。微软提供了[默认应用设置入口](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings)及[Windows 设置 URI 说明](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings)。

这两个菜单入口仅在 Windows 原生版显示，Android 和浏览器版隐藏。注册保存当前 EXE 的完整路径；移动或重命名便携 EXE 后，请从新位置启动，再点击“添加到右键打开方式”更新路径。默认 `.md` 的操作目标仅为 `.md`，其他支持扩展名可分别在 Windows 中选择默认应用。

## 启动帮助

首次打开会自动显示帮助。帮助先介绍 Windows 的打开方式与默认 `.md` 程序入口，再说明编辑和阅读、文件操作、TextPack、网页图文粘贴等常用功能。

勾选“下次不再展示”并关闭帮助后，以后启动不再自动弹出。该偏好保存在本机；需要重看时，可以通过“更多”→“使用帮助”手动打开。

## English

v0.5.1 adds two Windows actions for the portable EXE, plus startup Help with a remembered opt-out. This release ships Windows only; the Android APK remains at v0.5.0.

Choose **More → Add to Open with** to register the currently running EXE for the current user. It becomes an available handler for `.md`, `.markdown`, `.mdown`, `.mkd`, `.txt`, and `.textpack`, without administrator privileges. Existing default applications are retained.

Choose **Set as default for .md** to register the app and open Windows **Default apps** settings. Find `.md`, select **滚猫md**, and confirm in Windows. Supported Windows 11 versions can open the app-specific page; older systems open the general Default apps page. The application reports that Settings was opened, and the user completes the default choice there.

Both entries are hidden in Android and browser builds. Registration stores the full path of the running EXE. After moving or renaming it, launch it from the new location and choose **Add to Open with** again. The default-app action guides the choice for `.md`; defaults for other extensions can be selected separately in Windows.

Help opens automatically on first launch. It starts with the Windows file actions, followed by common editing, reading, file, TextPack, and web-paste workflows. Check **Don't show next time** and close Help to remember the preference locally and stop automatic startup display. **More → Help** remains available for manual access.

Validation on 2026-09-08 passed 238 JavaScript tests, 16 Rust tests, 5 Windows-menu browser flows, 10 startup-Help flows, and 13 TextPack browser regressions. Browser flows use real DOM and storage with mocked file and native interfaces. Registry tests use an isolated temporary subtree, and the real system default choice remains unchanged. The production build succeeded; the Windows EXE reports version 0.5.1 and is 6,655,488 bytes. SHA-256 is recorded above and was verified on the delivery copy. Native Explorer and system Settings selections remain untested. This release does not rerun Android packaging or device validation.
