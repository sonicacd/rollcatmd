# 滚猫md v0.5.3

v0.5.3 修复 Windows 版从所见即所得或阅读视图切到源码时跳至文末的问题。编辑光标留在文末时，切换后仍保持当前正在阅读的段落。

本次发布 Windows 便携版 EXE 与 SHA-256 校验文件。Android APK 继续使用 [v0.5.2](https://github.com/sonicacd/tumblingcatmd/releases/tag/v0.5.2)，本次未重新构建，尚未包含此修复。

## 修复内容

- **编辑器焦点与选区同步**：切换视图时通过编辑器同步焦点和 DOM 选区，避免延迟的选区事件将页面滚回旧光标所在的文末。
- **源码与预览的滚动同步**：恢复阅读位置期间暂停双栏同步，取消已有滚动动画和延迟回调，并按源码可视区对齐预览。恢复完成、用户开始操作或再次切换时，清理本轮恢复并恢复原同步状态。
- **回归覆盖**：使用包含 10,630 字符及 10 张图片的 TextPack 反复切换，检查鼠标按钮、`Ctrl+1/2/3`、阅读视图往返、源码双栏、快速切换和取消恢复。普通文档、大文档、三种主题及桌面/窄屏路径一并检查。

## English

v0.5.3 fixes Windows view switches that jump to the document end. Switching from WYSIWYG or Reader to Source preserves the paragraph being read even when the editing cursor remains at the end.

Two causes are addressed: delayed selection events after taking focus, and preview scroll animations that overwrite the restored source position. The editor now synchronizes focus and DOM selection, pauses competing scroll synchronization, cancels pending animations and callbacks, and aligns the preview with the source viewport. Completion, user input, and another view switch release the restoration and restore the previous synchronization state.

Regression coverage includes repeated switching with a 10,630-character TextPack containing 10 images, buttons and keyboard shortcuts, Reader round trips, the source/preview panes, rapid switching, and cancellation. Regular and large documents, three themes, desktop layouts, and narrow screens are also covered.

This release ships the **Windows v0.5.3 portable EXE**, **SHA256SUMS.txt**, and **rollcat-md.exe.sha256**. Android continues to use the [v0.5.2 APK](https://github.com/sonicacd/tumblingcatmd/releases/tag/v0.5.2); it was not rebuilt and does not include this fix.

Release validation on 2026-09-12 passed 246 JavaScript tests, 16 Rust tests, 43 reading-position checks, and 13 TextPack file/recovery checks. Browser suites reported no page errors; the TextPack save-failure test produced its expected injected error alert. The Windows production build succeeded, with existing bundle-size and dynamic-import warnings; the Rust release build took 3 minutes 45 seconds. The EXE reports file/product version 0.5.3, is 6,656,000 bytes, and contains this build's frontend JavaScript assets. Its SHA-256 is recorded above.

Browser checks use isolated Edge with real DOM/storage and mocked file/native interfaces. Native Windows WebView switching and Android device behavior remain unverified.
